# Pisang Goreng Bulan Majalengka — Official Website

Website landing page resmi untuk **Pisang Goreng Bulan Majalengka**, UMKM F&B pelopor camilan pisang goreng wijen renyah dan oleh-oleh khas Kota Angin Majalengka dengan standar transparansi 100% dapur bersih tanpa minyak jelantah.

---

## Fitur Utama Website

* **Heritage Editorial Aesthetic:** Mengusung identitas warna otentik kemasan box fisik (*Heritage Maroon `#7A1C1C` & Warm Ivory Cream `#FAF5EC`*) dengan tipografi klasik *Playfair Display* dan modern sans *Plus Jakarta Sans*.
* **Strict No-Emoji Standard:** Menggunakan inline SVG minimalis dan tipografi editorial bersih untuk tampilan profesional.
* **Transparansi Dapur 100%:** Memperkenalkan 4 pilar mutu dan 4 tahap ritual penggorengan higienis.
* **Katalog Menu & Kalkulator Pesanan:** Filter kategori produk, varian satuan & paket dus (isi 5 & 10), kalkulator harga instan, dan generator pesan WhatsApp otomatis ke hotline resmi `0821-1846-7453`.
* **Petunjuk Menghangatkan Interaktif:** Tab panduan menghangatkan untuk Teflon, Oven, Air Fryer, dan Microwave.
* **Outlet & Kru:** Galeri fasad kedai vintage kolonial, potret tim ramah, dan integrasi Google Maps.
* **Realtime Store Status:** Indikator otomatis jam buka kedai (10.00 – 21.00 WIB).
* **Mobile-First & Sticky Bar:** Navigasi cepat dan tombol pesan melayang untuk kemudahan akses pengguna smartphone.

## Cara Menjalankan Lokal

Website ini berbasis *pure static web technologies* (HTML5, CSS3, Vanilla JS) yang sangat ringan dan cepat.

```bash
# 1. Clone repository
git clone https://github.com/andiabdur/web-pisang-bulan-majalengka.git
cd web-pisang-bulan-majalengka

# 2. Buka langsung di browser atau jalankan server lokal:
python3 -m http.server 3000

# 3. Akses via browser di:
# http://localhost:3000
```
